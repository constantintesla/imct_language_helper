# imct_language_helper

Живой переводчик **русский → китайский**: говоришь по-русски, на странице появляется китайский текст, и его можно озвучить.

- **Речь → текст:** Web Speech API браузера (Chrome/Edge, `ru-RU`, потоково). Звук обрабатывается серверами Google.
- **Перевод:** локально через [Ollama](https://ollama.com) и модель Qwen2.5 (по умолчанию `qwen2.5:7b`). Учитывает три предыдущие фразы как контекст.
- **Озвучка:** нейронные голоса Microsoft Edge через `edge-tts` (нужен интернет). Голоса: Xiaoxiao, Xiaoyi, Yunxi, Yunjian.
- Сервер только на стандартной библиотеке Python, фронтенд — один HTML-файл.

## Установка

1. Установить [Ollama](https://ollama.com/download) и скачать модель:
   ```bash
   ollama pull qwen2.5:7b
   ```
2. Установить зависимость для озвучки:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

```bash
python server.py
```

Открыть http://localhost:8000 в Chrome или Edge, нажать «Говорить» и разрешить микрофон. Галочка «озвучивать» включает автоматическое проигрывание перевода.

## Настройка

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MODEL` | `qwen2.5:7b` | Модель Ollama. На слабом ПК без видеокарты быстрее `qwen2.5:3b` |
| `OLLAMA` | `http://localhost:11434` | Адрес Ollama |

PowerShell: `$env:MODEL="qwen2.5:3b"; python server.py`

## Производительность

На ПК без дискретной видеокарты (16 ГБ ОЗУ) 7b-модель переводит фразу за ~6 с, первая — ~16 с (загрузка модели).
