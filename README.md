# imct_language_helper

Живой переводчик **русский → китайский**, полностью локальный: говоришь по-русски — на странице появляется китайский текст и озвучивается. Работает в локальной сети (с телефона/ноутбука), микрофон подключается в браузере.

| Этап | Чем | Где |
|---|---|---|
| Речь → текст | [faster-whisper](https://github.com/SYSTRAN/faster-whisper) `large-v3-turbo` | GPU сервера |
| Перевод | любая модель в [LM Studio](https://lmstudio.ai) (по умолчанию `qwen/qwen3.5-35b-a3b`), учитывает 3 прошлые фразы | LM Studio |
| Озвучка | [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), 8 китайских голосов | GPU сервера |

Интернет нужен только при первой загрузке весов Whisper и Kokoro. Дальше можно запускать с `OFFLINE=1`.

## Установка (Windows, NVIDIA)

```powershell
python -m venv .venv
.venv\Scripts\pip install torch==2.8.0 torchaudio==2.8.0 --index-url https://download.pytorch.org/whl/cu128   # cu128 нужен для RTX 50xx
.venv\Scripts\pip install -r requirements.txt
```

В LM Studio: загрузи модель, включи **Developer → Start Server** (порт 1234).

## Запуск

```powershell
run.bat
```

Первый запуск скачивает модели и греет GPU (~1–2 мин). Сервер печатает адреса:

- `https://localhost:8443` — на этом ПК;
- `https://<IP ПК>:8443` — из локальной сети.

### Направления и голоса

Переключатель в шапке: **RU → 中文** (слушает русский, озвучивает китайский Kokoro) и **中文 → RU** (слушает китайский, озвучивает русский голосом «Санек»).

«Санек» — F5-TTS (дообученная русская модель ESpeech) с клонированием голоса по образцу `voices/sanek.wav`, ударения расставляет RUAccent, цифры и латиница проговариваются кириллицей (`speech_ru.py`). Реализация перенесена из `lms_translater_src`. Веса ESpeech (`models/espeech/espeech_tts_rlv2.pt`, ~2,6 ГБ) скопированы оттуда же и не лежат в git. Лицензия весов — CC-BY-NC-4.0 (только некоммерческое использование). Скорость речи: `SANEK_SPEED` (по умолчанию 1.2).

### Запуск в Docker

Нужны Docker Desktop (WSL2) с поддержкой GPU и запущенный LM Studio на хосте.

```powershell
.\run-docker.ps1          # определяет IP ПК для сертификата, собирает образ и запускает контейнер
docker compose down       # остановить
```

Контейнер видит LM Studio как `host.docker.internal:1234` (переопределяется `LMSTUDIO`), перезапускается автоматически (`restart: unless-stopped`). CA и сертификат лежат в `certs/`, веса моделей — в томе `models`. Если контейнер не достаёт до LM Studio, включи в нём «Serve on Local Network».

### Доступ из локальной сети

1. Один раз от администратора: `powershell -ExecutionPolicy Bypass -File open_firewall.ps1` (открывает порт 8443).
2. HTTPS обязателен: без него браузер не даёт доступ к микрофону на не-localhost адресах. Сервер при первом запуске создаёт свой локальный центр сертификации (`certs/ca.pem`) и подписывает им сертификат сервера (IP и имя ПК в SAN; при смене IP пересоздаётся сам).
3. **Один раз на каждом устройстве** поставь CA как доверенный — тогда предупреждений нет:
   - скачай `https://<IP ПК>:8443/ca.crt` (на первый раз нажми «Продолжить» в предупреждении) или скопируй `certs\ca.pem`;
   - **Windows**: `certutil -addstore -user Root ca.pem` (или двойной щелчок → Установить → «Доверенные корневые центры»);
   - **Android**: Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат CA;
   - **iPhone/iPad**: открыть `ca.crt` в Safari → Разрешить → Настройки → Основные → VPN и управление устройством → установить профиль; затем Основные → Об устройстве → Доверие сертификатам → включить «IMCT Translator Local CA»;
   - **macOS**: открыть `ca.crt` → Связка ключей → «Всегда доверять».
   Файл `certs/ca-key.pem` никому не передавай.

### Микрофон

Кнопка «Говорить» включает непрерывную запись. Паузы (~0.8 с) определяются в браузере, каждая фраза уходит на сервер, распознаётся Whisper, переводится и озвучивается. Полоска рядом с кнопкой показывает уровень сигнала. Чтобы озвучка не попадала обратно в микрофон, используй наушники или оставь включённое эхоподавление браузера.

## Настройка (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `MODEL` | `qwen/qwen3.5-35b-a3b` | id модели в LM Studio (список: `http://localhost:1234/v1/models`) |
| `LMSTUDIO` | `http://localhost:1234/v1` | адрес API LM Studio |
| `WHISPER` | `large-v3-turbo` | модель faster-whisper для русского |
| `WHISPER_ZH` | `large-v3` | модель faster-whisper для китайского (точнее turbo) |
| `PORT` | `8443` | порт HTTPS |
| `OFFLINE` | — | `1` — не обращаться к Hugging Face |

PowerShell: `$env:MODEL="google/gemma-4-26b-a4b"; .\run.bat`

Для моделей-«размышляющих» (Qwen3.x и др.) сервер передаёт `reasoning_effort: none`, иначе ответ приходит пустым.
